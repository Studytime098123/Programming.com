## About

task  to creat a simple s3 bucket with server-side encryption using terraform 

## prerequisites

Install Terraform on the working meachine ( [Terraform](https://developer.hashicorp.com/terraform/tutorials/aws-get-started/install-cli) )


## Steps

1. First initialize using the cmd 
  ```bash
     terraform init
  ```
2. check the contents of the resources that is being created
  ```bash
     terraform plan
  ``` 
3. apply the terraform file
  ```bash
     terraform apply
  ```
